PARTIE 2 // STRATÉGIE D'INGESTION "LAZY"

Optimisation & Performance

Problème:

Importer les 800k+ films de TMDB saturerait la DB gratuite (AuraDB).

Solution: Lazy Ingestion

Les films n'existent que virtuellement dans l'UI (via API TMDB). Ils ne sont créés (MERGE) dans Neo4j que lors d'une interaction utilisateur (Like, Vote).

MERGE (m:Film {id: $id})
ON CREATE SET
  m.title = $title,
  m.poster_path = $poster,
  m.vote_average = $vote
// Si le film existe, on ne fait rien
TMDB API (Raw Data)
Neo4j (Graph Data)
